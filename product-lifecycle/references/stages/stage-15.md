### 适合场景
试点结束，拿到结果数据。

### 目标
判断试点**测到了预期结果**吗？结果是否可信、可解释、可推广？

### 要回答的问题
1. 结果是不是"测出来的"，还是"看起来像"？
2. 数据质量如何（缺失、埋点异常、样本偏差）？
3. 分群之间有没有差异？差异是否影响结论？
4. 反面证据是什么？护栏有没有变化？成本是否符合预期？
5. 结论是成功、失败，还是**证据不足**？

### 关键问题
> **如果这个结论是错的，我们会因为什么而错？** 找不出这个 → 结果不可信，不下结论。

### 方法论
分检查项：数据质量 → 样本构成 → 观察周期 → 分群差异 → 反面证据 → 护栏变化 → 成本。
**三态裁决**：成功 / 失败 / 证据不足（第三态必须显式存在，不得省略）。

### 判断标准
| 判据 | 达标线 |
|---|---|
| 数据质量 | 完整性/异常/缺失已检查并记录 |
| 样本构成 | 写清与目标人群的差异及是否影响结论 |
| 周期充分 | 覆盖完整业务周期（避免只看首日） |
| 分群差异 | 已检查关键分群，不靠总体数字掩盖 |
| 反面证据 | 至少列 1 条不利证据并评估其影响 |
| 护栏变化 | 全部护栏的对比值 |
| 三态裁决 | 明确写出成功/失败/证据不足，不允许"基本成功" |

### 工作内容
1. 跑数据质量检查（缺失、异常、口径变更、埋点失效）。
2. 比对样本构成与目标人群；标注偏差方向。
3. 看分群差异（新老、角色、场景），定位结论适用的边界。
4. 汇总反面证据 + 护栏变化 + 实际成本。
5. 出三态裁决 + 限制说明 + 每条假设的状态（已确认/已推翻/仍未验证）。
6. 写下一步建议（放量/补测/返工/终止）。
7. **对账预测日志**：把本阶段及相关阶段在 `decisions/predictions.jsonl` 里的预测逐条回填结果
   （`hit` / `miss` / `partial` / `void`），并写 `outcome_note`：这次判断靠什么证据做对/做错。
   **打分必须依据事先写下的 falsifier，不是依据结果感觉**；结果"看起来不错"但 falsifier 没触发、
   也没证据显示成立 → 记 `partial`，不是 `hit`。

### AI 专项工作（仅 AI 产品适用）

**要回答的问题**
1. 失败模式分布是什么——哪一类失败吃掉了大部分损失？
2. 哪个分群被服务得更差？
3. 有哪些具体 badcase？根因是什么？
4. 这个结果的证据可信吗——样本构成、观察周期、是否只是没测到失败？

**关键问题**
> **"没有显著失败"不等于成功——** 我们是真的测过了，还是根本没测到？

**方法论**
按失败模式拆解（不只报总体通过率）＋分群差异分析 ＋反面案例清单 ＋
证据可信度检查（样本构成/周期/覆盖度）。

**判断标准**
| 判据 | 达标线 |
|---|---|
| 失败归因 | 按失败模式给占比与损失，不只给总体分 |
| 分群差异 | 指出最差分群并给出原因假设 |
| 反面案例 | 有具体 badcase + 根因，不是"有一些失败" |
| 可信度 | 写清样本构成、周期、未覆盖的场景 |

**工具**
`$PM/moh/skills/ai-ethics-review/SKILL.md` ·
`$PM/moh/skills/incident-postmortem/SKILL.md` ·
`python3 scripts/eval_stats.py slices <results.jsonl>`

**工作内容**
1. 把试点结果按失败模式拆开，逐类给占比与影响面。
2. 做分群差异分析：哪个分群通过率最低、为什么。
3. 抽具体 badcase 清单，逐条给根因分类。
4. 写证据可信度结论：样本构成、观察周期、未覆盖场景。
5. 判定结果状态：成功 / 失败 / 证据不足（分开处理）。

**原始材料与来源**
试点期 AI 指标日报、badcase 与回归集回流条目、人工改写记录。

**优先证据**
- **E1**：逐切片真实通过率与失败模式分布
- **E2**：badcase 里的用户原话

**产物**
- 失败模式归因分析（并入结果解读）
- 分群差异与 badcase 清单
- 证据可信度结论

**质量标准**
- "没有显著失败"不得写成成功；证据不足就是证据不足。
- 分群差异要给原因假设，不能只报数字。
- 反面证据与支持证据同权写出。

**门控补充条件**
- 只报总体通过率、未做失败模式归因 → 本阶段不得为 GO。

### 决策门控
- **通过 GO** → 阶段 16 决定发布并执行 GTM。
- **有条件通过 CONDITIONAL** → 证据不足 → 补试点/扩样本后重来。
- **返工 REVISE** → 结果为失败但方向仍值得 → 调整方案，回阶段 9。
- **终止 STOP** → 关键假设被推翻且不可修复 → 终止，归档结论。
