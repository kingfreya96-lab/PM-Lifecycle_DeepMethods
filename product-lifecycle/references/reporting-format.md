# 报告格式

> 从 SKILL.md §8 移出。阶段结束后需要固定标签报告时按需加载。


## 8. 报告结果

跑完必须把结论报出来，不能只说"已校验"。跑一次校验并报出**退出码**（0 = 通过，可能带警告；1 = 不通过）和警告原文。

报告用固定标签，一行一个：

```
STAGE_PICKED — 选了哪个阶段、为什么
L1_ANSWER — L1 的一句话答案
ARTIFACTS — 本阶段产出了什么产物（路径）
GATE_VERDICT — 裁决 + 一行理由
RECORD_FIELDS — 记录卡里实际填了的字段名（逗号分隔）
ISSUES — 技能本身的歧义/缺失/需要猜的地方，一行一个；没有就写 NONE
```

`ISSUES` 不是客套。文档与校验脚本互相矛盾、模板缺字段、阶段要求的产物在记录卡里无处安放——这些都要在这里点名。写技能的人下一轮才会照着改；只报"通过"等于把坑留在原地。

注意分工：`ISSUES` 行是给**技能本身**的，不是给这次判断的。这次判断的证据不足、样本薄、频率未知，写在记录卡的「反面证据」或「结论」里。
