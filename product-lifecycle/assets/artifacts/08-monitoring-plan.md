## 3. 红线与距离

> **不只看当前值，要看"距离红线多远"和"在往哪变"。**

| 指标 | 当前值 | 红线值 | 距离 | 趋势（7日斜率） | 状态 |
|---|---|---|---|---|---|
| | | | | 上升 / 平稳 / 下降 | 🟢 / 🟡 / 🔴 |

**状态规则**：
- 🟢 有余量且趋势稳定 → 继续
- 🟡 距红线 < 20% 或趋势恶化 → 准备处置动作，缩小范围
- 🔴 触线或趋势预测将触线 → 立即处置
