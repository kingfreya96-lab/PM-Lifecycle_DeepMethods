# 阶段产物 5 · 方案比较表（统一维度）

> **落点**：`stages/09-solution-validation/artifacts/solution-comparison.md`

## 规则

1. **维度必须统一**：所有方案用同一张维度表，逐维度对比。
2. **维度要可测**：完成率、步数、错误率、任务时长、可撤销性 —— 不能是"体验好"。
3. **落选方案必须写落选理由**。不写 = 方案还没比过。
4. **≥3 个候选**。只有 1 个方案 = 没做选择，等于没验证。
