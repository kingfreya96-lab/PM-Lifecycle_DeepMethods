## 〇、这份产物要回答什么

一句话：**"我们凭什么说这个 AI 功能变好了，而且明天不会悄悄变差？"**

- "变好了" → 黄金集 + 逐切片通过率 + CI 下界 + 与非 AI 基线的对照
- "不会悄悄变差" → 回归集 + 基线版本号 + CI 门禁 + 漂移监控

## 五、回归门禁配置

| 项 | 值 |
|---|---|
| 基线版本号（eval 集 + 判分脚本 + 基线分数） | `eval-v____` |
| 触发全量评测的变更 | prompt / 模型 / 检索 / 温度 / 工具编排 / 输出格式 |
| 总体通过率阻断阈值 | 相对基线下降 > 2pp |
| 切片通过率阻断阈值 | 相对基线下降 > 5pp |
| 安全切片 | 任一失败即阻断（容忍度 0） |
| P95 延迟阻断阈值 | 上升 > 30% |
| 单位成功成本阻断阈值 | 上升 > 20% |
