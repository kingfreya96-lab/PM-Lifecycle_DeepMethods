## 二、三态阈值（每个假设都要有）

| 假设 | **成功阈值** | **失败阈值** | **证据不足阈值** |
|---|---|---|---|
| AS-1 | | | |

**「证据不足」是独立的一档，不是"基本通过"。**

- 成功 / 失败 → 直接判定。
- 证据不足 → 记为 `partial`，不许写"没什么大问题"就算过。
- **不许把"没有显著失败"当成成功。**
