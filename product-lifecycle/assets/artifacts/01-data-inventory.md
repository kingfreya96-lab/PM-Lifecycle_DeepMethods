# 阶段产物 1 · 数据资产盘点表

> **落点**：`stages/01-discovery/artifacts/data-inventory.md`
> **什么时候做**：阶段 1 的第一个动作，在收信号**之前**。先知道手上有什么，再决定去找什么。

## 为什么要做这张表

顶尖团队阶段 1 的第一步不是收信号，是**盘数据资产**。
问题往往不是想出来的，是**从已经在手的数据里筛出来的**。
不盘点，就会在阶段 3 才发现"我们其实早就有这个数据，只是没取"。

## 一、已有的一手数据源（我们现在就能取到的）

| 数据源 | 具体到哪张表/哪个文件 | 能回答什么问题 | 口径与时间范围 | 样本量 | 取数方式与成本 | 等级 |
|---|---|---|---|---|---|---|
| 例：客服工单系统 | `工单导出表` sheet `raw` | 哪些问题高频、代价多大 | 全部工单，2026-07 至今 | — | SQL 一次导出 | E1 |
|  |  |  |  |  |  |  |

> **口径必须写死**：是"全部工单"还是"仅未关闭工单"？分母一变，所有结论翻转。

## 三、明确拿不到的（以及因此不能下的结论）

| 拿不到的数据 | 因此**不能**下的结论 | 可以改用什么 |
|---|---|---|
| 例：无历史定价实验数据 | 不能说"定价 X 能提升转化" | 做小样本定价测试（阶段 9） |

> **这一段是本表的重点。** 写下"因为拿不到 X，所以我不能说 Y"，
> 后面阶段就不容易做出无根据的断言。
